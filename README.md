# Plantillas predeterminadas

Plantillas de Issues y de pull requests que GitHub aplica a **todos los repositorios de `marcialrivas` que no tienen plantillas propias**. Si un repositorio tiene su propia carpeta `.github/ISSUE_TEMPLATE/` o su `pull_request_template.md`, se usan las suyas.

| Archivo | Qué es |
|---|---|
| `.github/ISSUE_TEMPLATE/` | 8 formularios: épica, historia, tarea técnica, bug, spike, deuda técnica, mejora de agente o skill, y riesgo. Sin Issues en blanco |
| `.github/pull_request_template.md` | Plantilla de PR con la DoD mínima y la checklist de revisión humana |

**No se edita aquí.** La fuente es la carpeta `templates/` del repositorio de plataforma. Los cambios se hacen allí por PR y después se copian a este repositorio, también por PR.

Este repositorio es público porque GitHub solo aplica plantillas predeterminadas desde un repositorio `.github` público. No contiene información sensible.
